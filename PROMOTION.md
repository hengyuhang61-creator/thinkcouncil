# ThinkCouncil launch copy

## English

**ThinkCouncil — an evidence hearing for a real decision.** Put your decision to the test. Give it two options and a set of sourced claims. See what evidence supports each side, which assumptions limit the answer, and when the result stays contested.

[Try the hearing](https://hengyuhang61-creator.github.io/thinkcouncil/) · [Release](https://github.com/hengyuhang61-creator/thinkcouncil/releases/tag/v0.1.0)

## 中文

**ThinkCouncil — 决策证据工作台。** 把决策放到证据面前。填写两个备选方向和带出处的材料，查看各方依据、可反驳点与尚未解决的冲突。

[打开演示](https://hengyuhang61-creator.github.io/thinkcouncil/) · [版本发布](https://github.com/hengyuhang61-creator/thinkcouncil/releases/tag/v0.1.0)

## Technical community draft

What should happen when a project has evidence for releasing now and a legitimate reason to wait? ThinkCouncil keeps the distinction between a source record, a derived result and a guess visible. Edit the MachAtlas example or bring your own decision. [Demo](https://hengyuhang61-creator.github.io/thinkcouncil/) · [Issues](https://github.com/hengyuhang61-creator/thinkcouncil/issues)

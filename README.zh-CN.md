# ThinkCouncil

**把决策放到证据面前。**

[打开公开演示](https://hengyuhang61-creator.github.io/thinkcouncil/) · [版本发布](https://github.com/hengyuhang61-creator/thinkcouncil/releases/latest) · [反馈](https://github.com/hengyuhang61-creator/thinkcouncil/issues/new)

输入一个问题、两个选项，逐条记录主张及出处。三个方法分别比较备选路线、寻找反例、检查主张能否追溯。可使用内置的 MachAtlas 发布问题，也可完整换成自己的问题。

依据来自输入者对材料的分类。两边都有材料支持时显示争议，只有假说时不会据此定案。输入留在当前标签页。方法经过项目改编，不代表任何真实人物发言或背书。
